# 申请信息与提交前核验

## 必须由申请人确认

- 先填写 [`application-draft.md`](./application-draft.md)，并为身份、日期、开发方式和权属信息标注可核验的证明来源；此草稿不是官方申请表。
- 申请人/著作权人法定全称、主体类型、证件号码及有效证件扫描件。
- 申请人与开发者关系、权利取得方式和权属证明；涉及委托、合作、职务开发、受让或承受的，准备相应合同、授权或证明文件。
- 软件全称、简称（如使用）、分类、版本号。建议与申请表及材料页眉统一为 `OGSystem 图形化智能体流程编排与运行管理系统`、`1.0.0`。
- 软件开发完成日期、首次发表状态及日期。若未发表，应按登记系统实际选项如实填写。
- 开发方式、硬件/软件环境、编程语言、源程序规模等申请表字段；按真实项目记录填写。
- 是否包含第三方组件、开源代码或受限材料；核查许可证和提交范围，不将不拥有权利的代码表述为自有成果。
- 申请表打印后的签章页签字/盖章及扫描件。

- [x] 从当前 `src/` 生成源程序前后各 30 页、每页 50 行的鉴别材料工作稿。

## 生成与复核

在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-copyright-materials.ps1
```

输出位于 `docs/copyright-output/`，包含 HTML 预览和登记用 PDF。脚本使用项目的 Playwright Chromium，不依赖 Microsoft Word。提交前用 PDF 阅读器逐页检查代码是否截断、页眉版本是否一致、手册是否少于 30 行/页；若版式或源码发生变化，应重新生成并复核材料。
