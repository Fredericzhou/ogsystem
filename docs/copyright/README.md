# OGSystem 软件著作权登记材料工作包

软件名称：OGSystem 图形化智能体流程编排与运行管理系统；版本号：1.0.0。材料状态：工作稿，待权利人核实后提交。

## 材料

- `user-manual.md`：按中国版权保护中心的软件登记指南编写的用户说明书。
- `application-draft.md`：可编辑的申请信息底稿，预留申请主体、著作权人、开发人员、日期、权属和签章等待确认字段。
- `application-checklist.md`：申请人需补齐的登记信息、权属证明和提交前检查项。
- `../copyright-output/`：由 `scripts/build-copyright-materials.ps1` 生成的 HTML 预览和 PDF 文件，包括 60 页程序代码鉴别材料。

## 事实边界

本工作包从候选版本 `1.0.0` 的源码、README、使用手册和公开登记指南整理。没有根据仓库推断著作权人、申请人身份、权利取得方式、开发完成日期、发表日期、开发人员名单或权属链。这些字段必须以合同、任职关系、项目记录及证件为准。

源程序鉴别材料从当前 `src/` TypeScript 源码按文件名排序后拼接，选择前 1,500 行和末 1,500 行，每页 50 行，共 60 页；每行标明文件和原始行号。该样本用于申请材料准备，不替代申请人对提交版本、权利归属和代码保密范围的审查。
