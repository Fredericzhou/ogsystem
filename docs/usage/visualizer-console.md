# OGS 多智能体图编排系统

OGS多智能体图编排系统用于编辑角色图、检查配置并执行单次试运行。图中的节点表示角色（每个角色可由一个 Agent 执行）；Flow 表示一个角色完成任务后向另一个角色交接，不表示事件、动作或流程步骤。

## 设计与调试

设计页的“配置”面板用于检查角色、Flow 和运行绑定。“调试”面板用于启动设计试运行，并按阅读优先级显示本次运行信息：

1. 运行状态与关键计数。
2. 角色执行事件及明确的角色到角色 handoff。
3. 人工评审状态。待处理评审会突出显示，可直接跳转到该次运行的评审页面进行决策。
4. 角色输入/输出，可从对应的角色执行记录打开。
5. 原始引擎和角色日志，默认折叠并按需加载。

若运行暂停等待人工评审，界面应明确标出等待状态和对应角色，不应将尚未发生的后续 Flow 显示为已完成的 handoff。

## 运行记录

设计页调试面板只展示最近一次设计试运行。运行页按运行 ID 查看完整历史，包括时间线、人工评审、诊断和运行产物。它们属于同一次运行的不同视图：事件日志记录过程，评审记录人工决策，角色 I/O 和快照保存执行产物；运行摘要是这些数据的概览，不替代原始记录。
