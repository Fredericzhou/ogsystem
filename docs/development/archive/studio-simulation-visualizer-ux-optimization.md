> **核心原则**：结构最优、零生硬 Emoji、行业顶级工业设计感（Linear / Vercel / Dify 风格）、极致深色模式高对比体验

## 一、 背景与全面设计目标

在 Studio 团队构建全生命周期（编排 -> 调试 -> 门禁 -> 运行）中，针对用户反馈与深入调研，本方案全面解决以下体验断点：

1. **图标设计语言割裂**：混用操作系统文本 Emoji（`⚙`、`⌛`、`⏱`、`🔄`、`⚡`、`⚠️`），不同平台表现不一且显粗糙，统一为 **1.5px 几何矢量 SVG 图标库**。
2. **群聊交互与状态呈现**：
   - 将“等待原因”更替为推进态「**工作中...**」；
   - 角色头像右下角徽标升级至 **18px 实体高光环**；
   - 修复长对话容器高度与 flex 伸缩模型，确保纵向滚动条**自由顺畅滚动且不截断**；
   - 顶部插入「**👤 用户发起**」起始气泡，还原真实工作群协同心智。
3. **图谱节点排版与防遮挡**：
   - 彻底解耦右上角状态图标与右下角指标标签，从几何坐标上杜绝重叠；
   - 指标标签显示最新一轮耗时与 Token，并支持**点击展开历史各轮次消耗对比**。
4. **X6 与 ELK 配套高级感升级**：
   - 消除深色模式下画布背景泛白 BUG（`.studio-graph-canvas` 补齐深色 `#0b1220` 背景与 `#1e293b` 点阵）；
   - 优化 ELK 导出的节点圆角、连线正交倒角（`radius: 6px`）、SCC 循环闭包群组的半透明黑曜石质感；
   - 连线与端点采用统一的 1.5px / 2px 矢量线宽，消除锯齿与粗细不均。
5. **深色模式高级对比度方案（High-Contrast Dark Theme）**：
   - 彻底重构深色模式下的角色色卡算法（`roleColorForId` 适配暗色模式：`hsl(hue, 38%, 18%)` 深色柔和底 + `hsl(hue, 80%, 70%)` 霓虹高对比轮廓）；
   - 画布所有文字、标签、气泡均符合 WCAG AAA 级对比度要求；
   - 运行态具备暗色专属发光光环（Glow Aura & Radar Pulse）。
6. **画布运行时全景 HUD 看板**：
   - 画布顶部悬浮轻量毛玻璃状态看板（运行时钟、节点进度 `2/4`、总 Token、一键平滑聚焦活跃节点）。

## 二、 核心设计体系与视觉规范

### 1. 全局矢量图标系统统一规范（Lucide-Grade Icon Standard）

全面剔除页面中的系统 Emoji，统一采用统一的 1.5px 线宽、圆角连接的矢量 SVG 图标规范：

| 场景 / 用途 | 原实现（Emoji / 散装） | 统一设计（标准 1.5px 矢量 SVG） | 视觉特征与动效 |
| :--- | :--- | :--- | :--- |
| **工作中 / 运行** | `⚙` 齿轮 Emoji 或粗糙 8 轮轴 | **Radar Spinner (双环雷达旋转环)** | 外环 270° 流动旋转，内核中心呼吸光斑，轻盈科技感 |
| **等待模型 / 工具** | `⌛` 沙漏 Emoji | **Fluid Sandglass / Clock (流砂沙漏/时钟)** | 暖琥珀金（`#f59e0b`），流光沙漏轮廓与流动点 |
| **等待人工审核** | 文本堆叠 | **Shield Eye (紫蓝呼吸护盾)** | 双色渐变光环，呼吸式瞳孔光标 |
| **执行完成** | `✓` 或普通绿点 | **Check Circle (薄荷绿勾选)** | 16px 圆形微光衬底，纤细清爽勾选 |
| **异常失败** | `⚠️` 警告 Emoji | **Alert Circle / Octagon (珊瑚红感叹号/叉号)** | 高警示饱和度，外圈呼吸闪烁 |
| **指标：耗时** | `⏱` 码表 Emoji | **Vector Clock (`<svg width="11" viewBox="0 0 24 24">`)** | 极简矢量表盘 |
| **指标：循环** | `🔄` 旋转箭头 Emoji | **Vector Rotate-Cw (`<svg width="11" ...>`)** | 极简顺时针圆弧箭头 |
| **指标：Token** | `⚡` 闪电 Emoji | **Vector Zap / Sparkles (`<svg width="11" ...>`)** | 极简电能图标 |
| **群聊：用户** | 纯文字或散装图标 | **User Avatar Capsule (矢量用户人形)** | 浅蓝底色，独立圆角矩形 |

### 2. X6 & ELK 配套高级感与深色模式对比度矩阵

针对深色模式（Dark Theme）与浅色模式（Light Theme）制定严格的色彩与阴影系统：

| 组件 / 元素 | 浅色模式（Light Theme） | 深色模式（Dark Theme - 高级黑曜石） | 视觉层次与对比 |
| :--- | :--- | :--- | :--- |
| **画布底色与网格** | `#f7faf8` + `rgba(57, 108, 87, .11)` 点阵 | `#0b1220` + `rgba(148, 163, 184, 0.14)` 柔和暗点 | 彻底消除深色模式下画布仍为白底的问题 |
| **节点容器 (Body)** | `#ffffff`，边框 `#dce8e2`，阴影轻微 | `#0f172a`，边框 `rgba(255,255,255,0.12)`，内发光 | 悬浮质感，不刺眼且边缘分明 |
| **角色底色与强调色** | 柔和粉蜡底 (`hsl, 42%, 95%`) + 深色字 | 深邃暗底 (`hsl, 38%, 18%`) + 霓虹轮廓 (`hsl, 80%, 70%`) | 深浅双模下均保持高辨识度与文字清晰 |
| **主标题与次要文字** | 标题 `#162822`，描述 `#64748b` | 标题 `#f8fafc`，描述 `#94a3b8` | 达到 WCAG AAA 级对比度 |
| **活跃流转边 (Active Edge)**| `#10b981` 翠绿流光，带阴影脉冲 | `#34d399` 至 `#38bdf8` 霓虹能量脉冲 | 高对比流光，一眼洞悉执行走向 |
| **循环回环边 (Loop Edge)** | `#55798c` 虚线，标注文字灰色 | `#38bdf8` 霓虹天蓝流光，悬挂 `🔄 循环 #N` 胶囊 | 强化循环与返工分支的可视化感知 |
| **SCC 循环群组背景** | 浅灰蓝半透明虚线框 | 深度暗蓝半透明 `rgba(30, 41, 59, 0.45)` + 细发光边框 | 聚合环路逻辑边界明确 |
| **运行时 HUD 看板** | 白底半透明毛玻璃 (`#ffffffcc`) | 暗夜毛玻璃 (`rgba(15, 23, 42, 0.85)`)，边框 `#334155` | 悬浮置顶，不喧宾夺主 |

### 5. 画布运行时全景 HUD 与触感反馈

#### ① 画布悬浮运行时 HUD 看板
```
┌───────────────────────────────────────────────────────────────────┐
│ 🟢 运行中 · 耗时 4.2s · 节点: 2/4 · Token: 3.8k · 🎯 聚焦活跃节点  │
└───────────────────────────────────────────────────────────────────┘
```
- 悬浮于画布顶部，支持实时动态秒表；
- 点击「🎯 聚焦活跃节点」即可平滑缓动平移画布中心，无论图谱多大都能一键跟进。

#### ② 节点微动效与智能焦点路径
- **完成涟漪（Done Ping）**：角色完成瞬间扩散一道温柔绿圈（300ms 渐隐）；
- **失败微震（Fail Shake）**：角色失败时轻微抖动并附带高对比度红框；
- **焦点路径微降噪（Focus Trail）**：活跃链路节点保持 100% 高光，非相关节点微淡化至 60%，运行结束后无缝淡出恢复。
